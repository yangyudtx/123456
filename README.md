## SafeCap：开源联锁/信号形式化验证工具简析

SafeCap 是一套面向铁路联锁/信号系统（尤其 SSI 等）的开源形式化验证工具。它用于在工程阶段对信号与联锁逻辑进行模型化与形式化验证，从而更系统地发现潜在逻辑风险，服务于事故预防、事故复盘与整改验证。

- 开源仓库：ennessione/safecap — https://github.com/ennessione/safecap
